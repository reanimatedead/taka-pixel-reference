収録基準（3条件をすべて満たすもののみ収録）

  1. 独立した複数ソースで報告されている
  2. 再現時に実害がある
  3. 対処法または回避策が記述できる

網羅は目的でない。基準を満たす項目が貯まる構造が目的。

ビルド番号で引く

手元のビルドID（例: CP2A.260705.006）を入力すると、そのビルドの素性（機種 / 地域 / OS・track / リリース日 / セキュリティパッチ / ARBフラグ）と、全不具合エントリの修正状況を3分類で表示します。前方一致の候補も出しますが、完全一致を優先します。

自分の端末のビルド番号の調べ方

  1. 設定 → デバイス情報 → ビルド番号
  2. adb shell getprop ro.build.id（要 開発者向けオプション + USBデバッグ有効化。adb 導入済みのPCから実行）
