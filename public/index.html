電話 / Gmail 主要機能の対応状況と設定

「どの世代から使えるか」を明記。4a では使えない機能が判断材料になる。

通話スクリーニング（日本語対応版）

対応: Pixel 7 世代以降で段階提供 → 8a / 9a / 10a は標準搭載。4a〜6a は日本語自動応答は不可
  1. 電話アプリ → 右上メニュー → 設定
  2. 通話スクリーニング を選択
  3. 「不明な番号からの着信」で自動スクリーニングの強度を選ぶ
  4. 着信時は画面の「スクリーニング」ボタンで手動起動も可

注意: 営業電話・詐欺電話フィルタとして実用的なのは 8a 以降。EOL 端末での着信対応は迷惑電話フィルタアプリ側に依存することになりリスクが残る。

レコーダー文字起こし（日本語）

対応: Tensor 搭載機（6a 以降）。4a / 4a 5G / 5a は英語のみ・精度低
  1. レコーダーアプリで録音開始 → 自動で文字起こしタブに反映
  2. 録音一覧 → 共有 → テキストとしてエクスポート（Obsidian転記に使用可）

Gmail: 自動仕分け（フィルタ + ラベル）

対応: 全機種（サーバー側機能のため端末世代に依存しない）
  1. Gmail（Web推奨）→ 検索バー右の 検索オプション
  2. From / 件名 / キーワードで条件を指定 → フィルタを作成
  3. 「ラベルを付ける」「受信トレイをスキップ」を選択
  4. 求人・API通知・請求など、送信元ドメイン単位で分ける

Gemini / アシスタント切替

対応: Gemini標準は 8a 以降。6a / 7a はアプリ導入で切替可。4a 系は従来アシスタントのみ
  1. Gemini アプリ → プロフィール → 設定
  2. Google のデジタル アシスタント → Gemini / アシスタント を選択

OS別不具合マトリクス（Android 11 → 17）

網羅は不可能な前提で、各OSの「定番症状 → 対策」のみ掲載。VERIFIED = 出典確認済み / UNVERIFIED = 要再確認。月例パッチ配信後にこのセクションを確認・追記する。last verified: 2026-07-24

A17Android 17（2026/6/16〜）— 対象: 6a / 7a / 8a / 9a / 10a 全機種
配信直後から深刻報告が多発した版。6a〜10a は月例修正パッチ（2026年7月以降）の適用状況を確認してから更新する。更新前フルバックアップ必須。
  • タッチ操作異常 VERIFIED — スワイプ方向の逆転・タップ無反応・入力の過剰認識/欠落がシステム全体で突発。対策: ①アクセシビリティのトリプルタップ(拡大操作)をOFF ②Pixel Launcher のキャッシュ削除（設定→アプリ→Pixel Launcher→ストレージとキャッシュ）③改善なければ修正パッチ待ち。画面故障と誤認して修理に出さない
  • 通信不能（5G→LTE落ち・モバイル接続不可・eSIM消滅） VERIFIED — 6a / 8a を含む広範な機種で報告。対策: 機内モードON/OFF → SIM再挿入 → ネットワーク設定リセット。eSIM消滅時は端末側で復旧不可のケースがありキャリア窓口で再発行
  • Wi-Fi接続時のみ一部アプリが通信不可 VERIFIED — 仕事用プロファイル利用環境で発生するバグとGoogleが公式に認め修正を明言。暫定対策: ①スーパーバッテリーセーバーを一度ON→OFF ②対象アプリのキャッシュ削除+無効化→再有効化 ③仕事用プロファイルの一時無効化
  • 再起動ループ・文鎮化 VERIFIED — 初期化・本体交換に至る報告あり。対策: 更新前フルバックアップ。発生時はリカバリーモード → Factory Image sideload → 復旧不可なら交換申請
  • アプリ起動遅延 UNVERIFIED — 更新後数日は再インデックス期間として様子見。継続時は再起動を数回
A16Android 16（2025/6〜）— 対象: 6a〜10a
  • Wi-Fi突発切断・「接続済みだが通信不可」 VERIFIED — 対策: ネットワーク設定リセット → Wi-Fi自動切替OFF → プライベートDNS OFF → ルーター再起動の順で切り分け
  • バッテリー異常消費（6a世代で顕著報告） VERIFIED — 対策: バッテリー使用状況で異常アプリ特定・ライブ壁紙/常時表示を一時OFF・学習が落ち着くまで数日待つ
  • 通知が届かない VERIFIED — 更新時に「バッテリーの最適化」が自動で「制限あり」に変更される事例。設定→アプリ→対象アプリ→バッテリー→「制限なし」へ戻す
  • 戻る操作無反応・画面ホワイトアウト VERIFIED — 対策: 保護フィルム感度確認 → ジェスチャー設定再確認 → 月例パッチ適用
  • 位置情報の一時的ズレ（省電力切替直後） UNVERIFIED — 対策: 高精度モード固定 or 切替直後の測位を待つ

教訓: Pixelは配信最速な分、初期バグを踏みやすい。メイン機は初回メジャー更新を2〜4週間遅らせるのが実用解。

トラブルシューティング（TS）

上から順に「全機種共通 → 世代固有の既知問題」。所有中の 4a の項目は必読。OSバージョン起因の症状は上の「OS別不具合マトリクス」を先に確認。

共通基本 TS フロー（全機種）
  1. 強制再起動: 電源ボタン 30秒長押し（画面フリーズ時もこれで再起動）
  2. セーフモード: 電源メニューの「電源を切る」を長押し → セーフモード。サードパーティアプリ起因かの切り分け
  3. アプリ単位: 設定 → アプリ → 対象アプリ → ストレージ → キャッシュ削除 → 改善なければデータ削除
  4. ネットワーク: 設定 → システム → リセット → Wi-Fi/モバイル/Bluetoothをリセット
  5. OSアップデート確認: 設定 → システム → ソフトウェアアップデート
  6. 最終手段: バックアップ → 初期化。復旧不能ならリカバリーモード（電源OFF → 電源+音量下 長押し）から Factory Image を sideload
4aPixel 4a（所有機）— EOL + バッテリー制限問題

状態: 2023年に全アップデート終了。さらに2025年1月の最終「バッテリー性能アップデート」で、一部個体はバッテリー容量・充電速度が意図的に制限された（発火リスク対策）。対象個体はGoogleが交換/返金プログラムを提供していた。

  • 電池の減りが急に悪化した場合: 故障ではなく上記アップデートの仕様の可能性が高い。設定 → バッテリー → 使用状況で確認
  • セキュリティ: 更新が来ないため、銀行・決済・仕事用アカウントのログインは非推奨。検証用・音楽プレーヤー・室内サブ機に限定
  • 膨張チェック: 背面パネルの浮き・画面の押し上げが出たら即使用中止（リチウム電池の膨張兆候）
  • 延命するなら: 非公式ROM含め、安全に延命する公式手段は実質ない
4a5G/5a4a (5G)・5a (5G) — EOL 共通
  • 両機とも Snapdragon 765G。動作自体はまだ実用域だがセキュリティ更新なし → 4a と同じ「サブ機限定」判断
  • 5a は電源ボタン陥没・膨張報告が比較的多い世代。中古購入は非推奨
6aPixel 6a — 指紋認証・発熱・モデム
  • 画面内指紋の精度が低い: 同じ指を角度を変えて2回登録すると改善。保護フィルムは指紋対応品のみ
  • 発熱・電池持ち: Tensor G1 世代共通。優先ネットワークを4Gにすると改善する場合あり
  • 通信が不安定: G1世代のモデム個体差。機内モードON/OFF → SIM再挿入 → ネットワークリセットの順で切り分け
  • 期限: 2027年7月でアップデート終了。残り約1年、買い替え計画を先に立てる
7aPixel 7a — 発熱・ワイヤレス充電
  • 充電中の発熱: ケース装着のままワイヤレス充電すると温度制御で充電が止まることがある。有線を基本に
  • 画面のちらつき報告: 明るさ自動調整OFF + 更新適用で改善例多数
  • 期限: 2028年5月まで。中古で買うならこの世代が実用下限
8a〜10aPixel 8a / 9a / 10a — 現役世代
  • 共通: 7年保証世代。問題発生時はまず月例アップデート適用 → 共通TSフロー → OS別マトリクス確認
  • 8a: 画面の緑かぶり報告はアップデートでほぼ解消済み。設定 → ディスプレイ → 画面の色味で微調整可
  • 9a: 一部ロットでバッテリー関連の出荷前対策があった世代。購入時はGoogleストアのサポート告知を確認
  • 10a: Tensor G4継続のマイナー更新世代。背面フラット化で卓上安定。GPU性能はG5より高い逆転現象があり、ゲーム用途では10無印より有利な場面もある
  • リカバリー: この世代は「修復モード」(Repair Mode) 搭載。修理に出す前に 設定 → システム → 修復モード でデータを隠せる
判断表用途別・使ってよい世代の早見
  • 銀行・決済・仕事アカウント: 6a以降のみ（＝更新が生きている端末のみ）。ただし6aは2027/7まで
  • 検証・開発サブ機: 4a〜5aでも可（ネットワークは検証用に分離）
  • 今買うならコスパ順: ① 型落ち9a（10a発売で値下がり中）② 10a ③ 中古7a（2028/5まで）
